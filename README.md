# Finance Manager

A Flutter UI prototype for viewing a sample balance, expense categories and spending charts.

## Features

- Dashboard with sample transactions
- Expense entry screen with category and date selection
- Statistics chart and refreshed indigo styling

## Stack

Flutter · Dart · Material widgets · fl_chart

## Run locally

```sh
flutter pub get
flutter run
```

See [SECURITY.md](SECURITY.md) for local Firebase configuration and API-key handling.

## Project status

The dashboard uses sample values. Several unfinished BLoC files remain in the repository; this is a UI prototype rather than a production finance service.
